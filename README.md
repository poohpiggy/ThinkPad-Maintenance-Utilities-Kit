# ThinkPad Maintenance Utilities Kit

本仓库收录 **ThinkPad Maintenance Utilities V1.11（x64）**，用于在 ThinkPad 更换主板后恢复机器类型和型号（MTM）、整机序列号、主板条码、机型名称和 UUID。我整理了中英双语的使用教程和 EFI 分析笔记，附完整反汇编和可以双击运行的 Windows 只读查询工具。

This repository contains **ThinkPad Maintenance Utilities V1.11 (x64)** for restoring the machine type model (MTM), system serial number, board barcode, product name, and UUID after a ThinkPad system board replacement. I included a user guide and EFI analysis notes in Chinese and English, along with the full disassembly and a read-only Windows checker you can run by double-clicking it.
